Quatre motifs de 32 pas (deux mesures), A à D. Un clic pose une note, un second l'efface ; empilez-en plusieurs dans une colonne pour faire un accord, ou passez le bouton Accords sur Mono pour n'en garder qu'une par pas. La rangée Acc. accentue le pas entier, la rangée Tenue le fait prolonger la note précédente — c'est ainsi que les nappes tiennent sur toute la mesure. Espace lance ou arrête, Ctrl+Z annule. Les barres claires marquent les temps forts.
Clavier : rangée du milieu = touches blanches, rangée du haut = noires, W / X (AZERTY) = octave −/+.
